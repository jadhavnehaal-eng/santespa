# Santé Spa Cuisine — Mumbai landing page

A static, single-page site (BKC & NESCO). No build step needed.

## Files
- `index.html` — the page (HTML, CSS and a small script for the NESCO/BKC ratings toggle)
- `assets/images/` — courtyard, gazebo and Green Pao Bhaji photos
- `assets/sante-menu.pdf` — the full menu linked from "See full menu"

## Run locally
Open `index.html` in a browser, or serve the folder: `npx serve .`

## Deploy
Drag this folder into Vercel / Netlify, or upload it to any static host.
